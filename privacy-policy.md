# Политика конфиденциальности бота "Пингви"

**Последнее обновление:** 27 мая 2026 г.

## 1. Общие положения
Бот "Пингви" (далее — "Бот") разработан командой Hutzker team. Настоящая Политика конфиденциальности описывает, какие данные собирает Бот, как они используются и хранятся.

## 2. Какие данные собираются
Бот может собирать и обрабатывать следующую информацию:
- **Идентификатор пользователя Discord** (User ID) – для связи настроек и команд с конкретным пользователем.
- **Идентификатор сервера Discord** (Guild ID) – для хранения конфигураций сервера (например, префикс команд, каналы для уведомлений).
- **Содержимое команд** – временно обрабатывается для выполнения действий и не сохраняется постоянно.
- **Логи ошибок** – только техническая информация (тип ошибки, время, вызвавшая команда) для улучшения работы Бота.

Бот **не собирает** личные сообщения пользователей, содержимое голосовых каналов, пароли, адреса электронной почты (кроме указанного в контактах разработчика) или платёжные данные.

## 3. Цели обработки данных
Собранные данные используются исключительно для:
- Обеспечения работы команд и функций Бота.
- Персонализации настроек на каждом сервере.
- Отладки и исправления ошибок.
- Предотвращения злоупотреблений и спама.

## 4. Хранение и передача данных
- Данные хранятся на серверах, используемых для работы Бота. Все меры безопасности приняты в соответствии с общепринятой практикой.
- Данные **не передаются** третьим лицам, за исключением случаев, предусмотренных законодательством (например, по требованию суда или правоохранительных органов).
- Бот не использует сторонние аналитические сервисы.

## 5. Права пользователей
Вы имеете право:
- Запросить копию ваших данных, которые хранит Бот.
- Потребовать удаления ваших данных (для этого свяжитесь с разработчиком по email, указанному ниже).
- Отозвать согласие на обработку данных, отказавшись от использования Бота на вашем сервере.
